# running.services

- Production origin: https://running.services (see `wrangler.jsonc`). Deploy through the existing Cloudflare Worker, using `npm run build` and `wrangler deploy`.
- Public products: race discovery and comparisons, race listings for organizers, and an authenticated read-only race API. Verify current claims on /for-organizers, /pricing, /developers, or in their source before publishing.
- Blog pages are generated by `shared/blog-months.ts`, `client/src/pages/blog-post.tsx`, and `server/ssr-prefetch.ts`. Prefer slug-specific content where only one URL qualifies.
- Race comparisons use the existing /vs route. Check both race records and the canonical pair before creating or linking a comparison.
- Acquisition focus: race organizers and developers. GA4 `generate_lead` is a count of successful form submissions and claims, not a count of qualified sales.
